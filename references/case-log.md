## 典型题型对照表

| 题型 | 推荐标注 |
|---|---|
| 口算 / 直接写得数（有 `=`） | `after` |
| 脱式计算 / 怎样简便就怎样算（无 `=`） | `blocks`，只写 `= 步骤` 链 |
| 竖式计算（虚线格子） | `verts`（自动排数位对齐 + 横线） |
| 竖式带 ★ | `verts` + 验算文本 |
| 比较大小（○） | `fills`，圆圈位置用 `rings()` 检测 |
| 括号/方框填空 | `fills` + 最大宽度自动缩字号 |
| 应用题 | `fills` 填结论 + `notes`/`blocks` 补算式 |
| 找规律 / 巧添符号 / 24点 | `fills`（窄空间用半角符号） |
